# DogFit

Локальный мобильный PWA-журнал тренировок. Программы, фактические подходы, таймеры отдыха, история, силовой прогресс и измерения сохраняются на устройстве в IndexedDB.

## Запуск

Нужен Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Проверка production-сборки:

```bash
pnpm typecheck
pnpm test -- --run
pnpm build
pnpm preview
```

## Установка на iPhone

Для установки PWA на физический iPhone сайт должен открываться по HTTPS. Откройте его в Safari, нажмите «Поделиться» → «На экран Домой». Платный сервер приложению не нужен: после первой загрузки интерфейс и сохранённые данные доступны офлайн. Для доступа с разных устройств потребуется отдельная синхронизация или регулярный экспорт резервной копии.

## Данные и резервная копия

- Данные находятся только в IndexedDB текущего браузера.
- В разделе «Профиль» можно экспортировать JSON-копию и восстановить её после проверки версии и структуры.
- Очистка данных Safari или удаление сайта может удалить локальную историю, поэтому экспорт важен.

## InBody

Основное приложение не зависит от InBody. Реализованы ручной ввод и безопасная оболочка импорта: камера, изображение/скриншот и вставка содержимого или ссылки. Распознавание QR отделено от импорта показателей, неизвестные ссылки не запрашиваются автоматически, повторный подтверждённый импорт отсеивается по отпечатку.

Поддерживаемый тестовый формат — JSON с `format: "wolf-fit-inbody-v1"`. Для настоящей интеграции нужен обезличенный пример реального QR либо официальные доступы Web API/OAuth и документация конкретного источника данных.

## Проверено

- точное преобразование `lb ↔ кг` без накопления округления;
- четыре варианта сравнения подходов и отдельные статусы пропуска/дополнительного подхода;
- разные переходы отдыха между подходами и после упражнения;
- восстановление таймера по сохранённому времени окончания;
- независимость снимка тренировки от последующих изменений программы;
- приоритет предыдущей тренировки той же программы;
- адаптивность без горизонтальной прокрутки на 360, 390, 430 и 1280 px;
- TypeScript, 13 автоматических тестов и production-сборка.

Проверка выполнялась в браузерной эмуляции. Физический iPhone не использовался.
